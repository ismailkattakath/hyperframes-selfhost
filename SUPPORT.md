# Support

## Getting help

1. Read [README.md](./README.md) and [docs/SETUP.md](./docs/SETUP.md)
2. Search [existing issues](https://github.com/ismailkattakath/hyperframes-selfhost/issues)
3. Open a [bug report](https://github.com/ismailkattakath/hyperframes-selfhost/issues/new/choose) with sanitized logs

## Security

See [SECURITY.md](./SECURITY.md). Do not post secrets or vulnerability details publicly.

## Upstream components

Problems in the underlying tools belong upstream when possible:

| Component | Project |

| Kinocut MCP | https://github.com/KyaniteLabs/kinocut |
